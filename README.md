# 23F-0872_23F-0698-AI-Assignment1
# GOOD PERFORMANCE TIME APP

AI Pathfinder Visualization using Uninformed Search Algorithms.

## Implemented Algorithms

- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Uniform-Cost Search (UCS)
- Depth-Limited Search (DLS)
- Iterative Deepening DFS (IDDFS)
- Bidirectional Search

## Features

- Step-by-step animated visualization
- Clockwise node expansion (including diagonals)
- Frontier and explored node highlighting
- Final path highlighting
